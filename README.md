# Fox Center

Mediacenter im Kodi-Stil für Android, Android TV und Fire TV. Design by Mr.Fox.

- **Videos:** Filme und Serien vom Gerät (Serien werden am Namen erkannt, z. B. `Serie S01E02.mkv`), Weiterschauen, Gesehen-Haken, Favoriten
- **Netzwerk:** Mediaserver im WLAN (DLNA: FRITZ!Box, NAS, Plex, Jellyfin, Emby), WebDAV (z. B. Nextcloud) und HTTP-Ordner
- **Musik:** Titel, Alben, Künstler, Ordner, Zufall, Wiederholen
- **Live-TV:** eigene M3U-Senderlisten mit Gruppen, Suche und Lieblingssendern
- **Bilder:** Alben, Vollbild, Diashow
- **TMDb (freiwillig):** Poster, Bewertung und Inhalt mit eigenem kostenlosen Schlüssel
- Bedienung mit Fernbedienung (Pfeile, OK, Zurück), Player mit Media3 (HLS, DASH, MKV, Untertitel)

Die APK baut GitHub Actions bei jedem Push, sie liegt dann unter *Releases*. Updates gibt es in der App über Einstellungen › App-Update.

Fox Center bringt keine Filme oder Sender mit – es spielt ab, was dir gehört oder frei verfügbar ist.
